## 一、精简示例（AI 速读版）

更新流程参数节点（upvariable → 真实类型 `data_update_variable`）：把触发记录字段值或固定值写入预先定义的流程参数，后续节点（尤其是分支条件）可引用这些参数。

### 1. 更新流程参数节点（upvariable）

```python
{
    "type": "upvariable",
    "name": "更新流程参数",
    "updateVariable": [
        # ① 普通参数：取触发记录字段值（type 省略 = "variable"）
        {
            "field": "name",                 # 流程参数变量名（需在 start.variableList 中预定义）
            "compType": "input",             # 参数控件类型（input/number/date 等）
            "valueType": 2,                  # 2=取表单字段值
            "val": {                         # val 对象 = 变量引用（formNodeType 枚举同 formModel）
                "variableValue": "input_1775629274119_420857",  # 来源字段 model
                "formTableCode": "ke_hu_shen_qing_co38",        # 来源表编码
                "variableName": "客户名称",                      # 来源字段显示名
                "formNodeType": "table",     # table=触发节点（start）字段
                "formNodeId": "start",
                "formNodeName": "工作表事件触发",
            },
        },
        # ② 数字类型参数，结构同上
        {
            "field": "money",
            "compType": "number",
            "valueType": 2,
            "val": {
                "variableValue": "money_1775629278035_887563",
                "formTableCode": "ke_hu_shen_qing_co38",
                "variableName": "注册金额",
                "formNodeType": "table",
                "formNodeId": "start",
                "formNodeName": "工作表事件触发",
            },
        },
        # ③ date 类型：固定日期赋值，val 为 ISO 字符串，⚠️ 不带 valueType
        {
            "type": "date",                  # type="date" 走固定值赋值
            "field": "birthdate",
            "compType": "date",
            "val": "2026-04-14T09:07:44.076Z",
        },
    ],
}
```

### 2. 生产数据提炼的关键知识点

1. **`type` 字段决定赋值方式**：条目省略 `type` 时默认为 `"variable"`（val 为变量引用对象，带 valueType=2）；`type: "date"` 时 val 为 ISO 字符串固定值且**无 valueType 字段**——脚本 build_upvariable_node 对非 date 条目才补 valueType（默认 2），date 条目不生成该字段。
2. **流程参数必须先定义再更新**：生产数据中 start 节点的 `variableList` 预定义了 name/money/birthdate 三个参数（结构：id、type、options.format、field），updateVariable 中的 `field` 必须与之一致。⚠️ 脚本当前将 start.variableList 固定输出为空列表，需在创建后手动 patch 或先在流程设计器中添加参数。
3. **val 对象的 formNodeType 枚举与 data_add 的 formModel 完全一致**：table=触发记录字段、search=get_one 结果、getMore=多条数据、function=运算节点结果（variableValue="result"）、system=系统变量（nowDate）。
4. **根节点 startType 双写**：生产数据根节点 `startType: "manual"`，真实触发类型在 `attr.startType: "tableEvent"`（历史遗留格式）；新生成数据两者一致。排障时以 attr.startType 为准。
