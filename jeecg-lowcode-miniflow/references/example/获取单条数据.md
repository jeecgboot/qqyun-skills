## 一、精简示例（AI 速读版）

获取单条记录（get_one，实际类型 data_get_one）有 3 种取数方式，对应 selectType；本示例还串联了 get_more（获取多条）与"从多条数据中取单条"。

### 1. 从工作表直接查询单条（get_one，selectType=1）

```python
{
    "type": "get_one",                            # 实际生成 type=data_get_one
    "id": "task966306100678926336",               # ⚠️ 自定义 ID，供下游 selectType=3 节点引用
    "name": "从工作表获取单条",
    "selectType": 1,                              # 1=从工作表直接查询
    "formTableCode": "ding_dan_shen_qing_c5dg",
    "formTableName": "订单申请",
    "conditions": [                               # 简化条件列表，脚本转为 searchFieldGroup
        {
            "rule": "ge",                         # 比较符代码
            "ruleName": "大于等于",                # 比较符显示名
            "valueType": "1",                     # 1=固定值
            "val": 1775577600000,                 # ⚠️ 日期条件值=毫秒时间戳（数字，非字符串）
            "name": None,
            "field": "date_1775640531752_255416", # 目标表字段 model
            "columnName": "订单日期",              # 字段显示名
            "type": "date",
            "valType": "date",
        }
    ],
    "sortField": "date_1775640531752_255416",     # 排序字段（orderField 同义）
    "sortType": "desc",                           # desc=倒序（取最新一条）
    "emptyAction": 2,                             # 2=在工作表中新增记录后继续执行（枚举：1=继续执行/3=中止或进分支，见 node-types 十二节）
}
```

### 2. 从关联字段取单条（get_one，selectType=3）

```python
{
    "type": "get_one",
    "id": "task966306407311908864",
    "name": "从关联字段获取单条",
    "selectType": 3,                              # 3=从上游记录的关联字段（link-record）取单条
    "formTableCode": "ding_dan_shen_qing_c5dg",   # 源表编码（主表）
    "formTableName": "订单申请",
    "sourceTaskId": "task966306100678926336",     # ⚠️ 上游 get_one 节点 ID（它查到的记录）
    "relationField": "link_record_1775648472154_528874",  # link-record 关联字段 model
    "conditions": [
        {
            "rule": "ge", "ruleName": "大于等于", "valueType": "1",
            "val": 100,                           # 金额条件=纯数字
            "field": "money_1775648515469_608087",
            "columnName": "单价", "type": "money", "valType": "money",
        }
    ],
    "sortField": "money_1775648515469_608087",
    "sortType": "asc",
    "emptyAction": 3,                             # 生产数据此处取 3，脚本原样透传
    "attr": {
        "linkFormTableCode": "sub_table_design_1775648472154_528874",  # 关联子表编码
        "linkFormTableName": "订单明细",
        "linkFormTableType": 1,
    },
}
```

### 5. link-record 关联查询条件写法（实战要点）

当触发表单通过 link-record 控件选择了目标表某条记录、需要按该关联去查目标表时，**查询条件用 `field: "_id"`（目标表记录id），val 引用触发表单的 link-record 字段 model**：

```python
# 片段：赋值给变量后作为 get_one 节点的 conditions 值使用
conditions = [
    {"rule": "eq", "ruleName": "等于", "valueType": 2,   # ⚠️ valueType=2（变量），不是 1（固定值）
     "val": {"variableValue": "<触发表单link-record字段model>", "formTableCode": "<触发表单code>",
             "variableName": "<字段名>", "formNodeType": "table", "formNodeId": "start",
             "formNodeName": "工作表事件触发"},
     "name": "<目标表字段名>", "field": "_id", "columnName": "记录id",
     "type": "input", "valType": "variable"}
]
```

要点：

- 条件字段必须写 `"_id"`（目标表的记录id 系统字段），**不能把 link-record 字段 model 当 field 用**；
- `valueType=2` 表示 val 是变量引用；val 对象里 `formNodeType: "table"` + `formNodeId: "start"` 表示取值自触发节点；
- 若按"触发表单当前记录 id"过滤（如查与触发记录同 _id 的子表记录），val 的 variableValue 写 `"_id"`（见《获取多条数据.md》生产数据）。

### 6. 生产数据提炼的关键知识点

1. **selectType 三态决定取数来源**：1=工作表查询、2=上游 get_more 结果、3=上游记录的 link-record 关联字段；selectType=2/3 必须给 `sourceTaskId`（上游节点 ID），因此上游节点要自定义 `id`。
2. **日期条件的 val 是毫秒时间戳数字**（如 1775577600000），不是日期字符串；金额条件直接给数字（如 100）。
3. **selectType=3 需要额外三个 link 字段**：`linkFormTableCode`/`linkFormTableName`/`linkFormTableType`（放 attr 里），缺失则 formTableList 中该节点无法正确关联子表。
4. **formTableId 规则**：selectType=1 → `form_{节点ID}_{表code}`；selectType=2/3 → `form_{上游节点ID}_{表code}`，脚本自动生成，无需手写。
5. **get_one 的 formModel 生产数据里带预填值**（funText/固定值/nowDate 等，用于"无数据时新增"场景），脚本统一生成 `{}`；如需预填，通过 attr 透传 formModel。
6. **noDataType 真实枚举**：1=继续执行、2=在工作表中新增记录后继续执行、3=中止流程或继续执行查找结果分支（未显式选择默认 0）；生产数据 1/2/3 均出现过。
7. **not_empty 条件的 val 是空串**（`"val": ""`）；生产数据该条件 `name` 为 `[]`（前端异常值），用脚本精简格式时省略 name 即可（默认 None）。
