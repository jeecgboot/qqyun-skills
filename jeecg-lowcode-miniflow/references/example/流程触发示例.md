## 一、精简示例（AI 速读版）

config 顶层 `startType` 枚举：`tableEvent`（工作表事件）、`buttonEvent`（按钮）、`timerEvent`（定时）、`dateFieldEvent`（按日期字段）、`userEvent`（人员事件）、`manual`（手动发起）、`subEvent`（子流程，见主子流程配置示例）。

### 1. 工作表事件触发（tableEvent）

```python
{
    "processName": "客户信息触发流程",
    "processKey": "process1775629000001",
    "lowAppId": "xxx",
    "startType": "tableEvent",
    "formTableCode": "ke_hu_shen_qing_co38",      # 监控的工作表编码
    "formTableName": "客户信息",
    "titleField": "input_1775629274119_420857",   # 标题字段 model
    "startEventType": "add|update",               # 触发事件，见下表
    "startCondition": [                           # 可选：满足条件才触发
        {
            "id": "969586911868002304",           # 雪花 ID
            "matchType": "",                      # ""=AND，"or"=OR（多条件时）
            "queryItems": [
                {
                    "rule": "eq", "ruleName": "等于",
                    "valueType": "1",             # "1"=固定值
                    "val": "个人客户",            # 条件值（类型跟随字段）
                    "name": None,
                    "field": "select_1775648798126_168238",   # 字段 model
                    "columnName": "客户类型",     # 字段显示名
                    "type": "select",             # 字段控件类型
                    "valType": "select",
                }
            ]
        }
    ],
    "conditionFields": ["input_1775629274119_420857"],   # 监控字段（update 时填）
    "nodes": [...],
}
```

**startEventType 枚举（下表「createStartNode」列是平台历史样本的观察值，不是必须值）：**

| startEventType | 触发时机 | createStartNode（平台样本观察值） |
|---|---|---|
| `add\|update` | 新增或更新 | `false` |
| `add` | 仅新增 | 样本里 `true`／`false` 都有 |
| `update` | 仅更新 | `false` |
| `delete` | 仅删除 | `false` |

> ⚠️ **本 skill 建流一律默认 `createStartNode=False`（不启用发起人节点）**，不必按上表对应关系去 patch；仅用户点名要发起人节点时才传 `"createStartNode": True`（2026-09-11 裁定）。

常用条件规则：`eq` 等于、`ne` 不等于、`gt` 大于、`ge` 大于等于、`lt` 小于、`le` 小于等于、`like` 包含、`null` 为空、`notNull` 不为空。

### 2. 定时触发（timerEvent）

```python
{
    "startType": "timerEvent",
    "beginDateStr": "2026-04-08 08:00",    # 首次执行时间
    "endDateStr": "2026-04-09 16:48",      # 结束执行时间（用户要求"到XX结束"时必填）
    "timeCycleName": "每天",               # 每分钟/每小时/每天/每周三/周一到周五/每月1号/自定义
    "nodes": [...],                        # 定时流程无工作表绑定，不能引用 start 表字段
}
```

**自定义 Cron（timeCycleName="自定义"）：**

```python
{
    "startType": "timerEvent",
    "beginDateStr": "2026-04-08 08:00",
    "endDateStr": "2026-04-09 17:03",
    "timeCycleName": "自定义",
    "cronExpr": "0 0 8 * * ?",             # Quartz Cron，或按以下区间配置
    "hourType": 2,                         # 2=范围
    "hourValueMin": 0, "hourValueMax": 10,
    "times": ["2026-04-08 08:00:00", "2026-04-08 09:00:00"],  # 具体执行时刻列表
    "nodes": [...],
}
```

### 3. 按日期字段触发（dateFieldEvent）

```python
{
    "startType": "dateFieldEvent",
    "formTableCode": "ding_dan_shen_qing_c5dg",
    "formTableName": "订单申请",
    "titleField": None,
    "triggerField": "date_1775640531752_255416",   # 监控的日期字段 model
    "triggerFieldType": "date",                    # date / datetime
    "executeType": 2,            # 1=到期当天 2=到期前 3=到期后
    "plusDate": "1",             # ⚠️ 偏移量必须是字符串 "1"，不是数字 1
    "plusDateUnit": 3,           # 1=分钟 2=小时 3=天
    "executionTime": "01:00",    # 每天执行时刻
    "cycleType": 1,              # 0=不重复 1=每年 2=每月 3=每周
    "linkFormTableName": "订单日期",   # 触发字段显示名
    "startCondition": [...],     # 可选，同 tableEvent 结构
    "nodes": [...],
}
```

### 4. 人员事件触发（userEvent）

```python
{
    "startType": "userEvent",
    "userEventType": 1,      # 1=入职 2=离职
    "nodes": [...],
}
```

脚本自动生成固定 formTableList：`sys_user` 表 + nodeType="userEvent"，无需表单绑定。

### 5. 自定义按钮触发（buttonEvent）

```python
{
    "startType": "buttonEvent",
    "formTableCode": "ke_hu_shen_qing_co38",
    "formTableName": "客户信息",
    "titleField": "input_1775629274119_420857",
    "nodes": [
        {
            "type": "data_update",
            "name": "更新记录",
            "formTableCode": "ke_hu_shen_qing_co38",
            "formTableName": "客户信息",
            "formTableSourceTaskId": "start",
            "updateFields": [
                {"field": "select_1775649166520_177631", "val": "成交客户",
                 "fieldType": "select", "type": "select"},
            ],
        }
    ],
}
```

按钮本身需另外通过 Desform 按钮 API 创建并绑定（见 references/api-reference.md），流程只负责按钮点击后的逻辑。

### 6. 生产数据提炼的关键知识点

1. **根节点 startType 与 attr.startType 双写**：老数据根节点恒为 `"manual"`（真实类型看 attr.startType），新数据两者一致；子流程根节点恒为 `"manual"` + `attr.startType: "subEvent"`。排障时以 attr.startType 为准。
2. **startCondition 结构固定**：`{id, matchType(""=AND / "or"=OR), queryItems[{rule, ruleName, valueType:"1", val, name:null, field, columnName, type, valType}]}`；val 类型跟随字段控件（select 为字符串、number 为数字 10）。
3. **conditionFields（监控字段）规律**：`add|update` / `update` 场景填监控字段 model 数组，`add` / `delete` 场景为空数组。⚠️ 脚本当前固定输出 `[]`，需要时创建后 patch。
4. **createStartNode（是否启用「发起人节点」）**：生产样本里 add 场景 true/false 都有，**不是平台强制**；⚠️ 本 skill 一律默认 `False`，**不要 patch 成 true**，仅用户点名要发起人节点时才在 config 传 `"createStartNode": True`（2026-09-11 裁定）。
5. **timerEvent 的 attr.timeCycle 是字符串数字编码**（"1"=每分钟、"2"=每小时、"3"=每天、"custom"=自定义），⚠️ 必须是字符串（整数编码前端下拉无法匹配，会显示原始数字）；timeCycleName 不能为 null（否则 timeCycle 变 "custom"，不按预期周期执行）。
6. **timerEvent 不绑定工作表**：formTableList=[]、hasVariableList=false、formTableId/formTableCode 均为 null/""；定时流程里不能引用 start 表字段。
7. **dateFieldEvent 的 plusDate 是字符串**（"1" 不是 1）；生产数据 formTableId 为 form_start_xxx 旧格式，trigger-types.md 建议传真实 DB id（避免 UI 工作表名显示错误）。
8. **buttonEvent 与 tableEvent 的差异**：attr.formTableId=null（tableEvent 为 form_start_xxx）；formTableList 首条无 selectType/level/formTableMainCode，且没有 variable 条目；生产数据 attr 无 selectType 字段。
9. **userEvent 生产数据无 userEventType 字段**（老版本省略），脚本支持 userEventType（1=入职 2=离职）。
