## 一、精简示例（AI 速读版）

消息节点对应脚本 `type: "notice"`，用 `noticeType` 区分渠道；保存后真实节点 type 是另一套枚举：

| noticeType（config 写法） | 真实节点 type | attr.type | 说明 |
|---|---|---|---|
| `system` | `message_system` | `system` | 系统消息 |
| `email` | `message_email` | `email` | 邮件通知 |
| `dingding` | `message_ding` | `dingtalk` | 钉钉消息 |
| `weixinqy` | `message` | `wechat_enterprise` | 企业微信消息 |

接收人 ID 必须带前缀：`user.xxx`（用户）/ `role.xxx`（角色）/ `dept.xxx`（部门）。

### 4. 邮件（noticeType: email）——带抄送

```python
{
    "type": "notice",
    "name": "发送邮件",
    "noticeType": "email",                   # 真实 type=message_email，attr.type=email
    "attr": {
        "noticeTitle": "系统邮件-发送",
        "noticeContent": "联系人：{{84f74f5812367eef0cff7c686c10a709.联系人}}\n联系电话：{{0bc9d62afef43ac7a2856eefadca6ca7.联系电话}}",
        "jsonContext": {...},                # 字段占位符映射（规则同企业微信）
        "sendType": 1,                       # email 专属：发送类型
        "toUserIds": ["user.admin"],
        "toUserNames": ["admin"],
        "copyToUserIds": ["user.qinfeng"],   # email 专属：抄送人 ID 列表
        "copyToUserName": ["秦风"],           # 抄送人名称列表
        "copyUserExpression": "",            # 抄送动态表达式（可留空）
    },
}
```

### 5. 生产数据提炼的关键知识点

1. **noticeType 与真实 type 是两套枚举**：config 写 `noticeType: "weixinqy"`，脚本生成 `type: "message"` + `attr.type: "wechat_enterprise"`；手改 JSON 时两处都要写对，否则前端下拉框无法匹配渠道。
2. **接收人 ID 必须带前缀**：`user.xxx` / `role.xxx` / `dept.xxx`（如 `user.zhangli`、`role.admin`、`dept.c6d7cb4deeac411cb3384b1b31278596`）。`toUserIds` 同时存在于 attr 内和**节点顶层**（脚本自动写两处；手改 JSON 时只写 attr 会导致收不到消息）。
3. **模板占位符规则（实测验证）**：`{{hash.字段名}}` 中 hash = md5(字段引用 JSON 字符串)，`jsonContext[hash]` = 同一 JSON 的 base64；字段引用 JSON 固定 4 键 `{"field","formTableCode","nodeId","nodeType"}`（注意是 `nodeId`，与运算节点 funContext 的 8 键 `formNodeId` 结构不同）。纯静态文本消息不需要 jsonContext。
4. **各渠道专属字段**：email 有抄送三件套（`copyToUserIds`/`copyToUserName`/`copyUserExpression`）+ `sendType`；system 有 `receiveType`；dingding/weixinqy 无额外字段。
5. **`toUserExpression`（如 `${applyUserId}`）实测不可靠**（脚本注释：消息会静默丢失），动态接收人优先用 `toUserIds` 指定。
6. 节点 content 摘要（"通知人:" + 名称列表）、`expressionValue: "${messageDelegate}"` 由脚本自动生成，无需手写。
