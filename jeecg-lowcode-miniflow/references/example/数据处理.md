## 一、精简示例（AI 速读版）

### 1. 添加记录（data_add）

自动向指定工作表新增记录。核心是 `formModel`：key=目标字段 model，value=字段值配置对象。

**① 单条新增，字段值引用触发节点（start）字段：**

```python

    "name": "添加一条记录",
    "addDataType": 1,                        # 1=单条新增（默认）
    "formTableCode": "ding_dan_shen_qing_c5dg",

            "formTableCode": "cai_gou_shen_qing_swdd",      # 来源表编码
            "variableName": "采购名称",                       # 来源字段名（展示用）
            "fieldType": "input",
            "formNodeType": "table",          # 引用类型：table=触发节点字段
```

**formModel 的 formNodeType 枚举：**

| formNodeType | 说明 | variableValue 写法 |
|---|---|---|
| `table` | 来自 start 触发节点字段 | 来源字段 model |
| `search` | 来自 data_get_one 查询结果 | 查询结果字段 model |
| `getMore` | 来自 data_get_more 多条数据（逐条引用） | 源表字段 model |
| `function` | 来自运算节点 | `"result"` |
| `plus` | 来自上游 data_add 新增主键 | `"_id"` |
| `system` | 系统变量 | `"nowDate"`（当前日期）等 |

### 2. 更新记录（data_update）

更新指定记录的字段值。**关键：`formTableSourceTaskId` + `formTableSourceNodeType` 决定更新哪条记录**——更新触发记录用 `start`/`table`，更新查询到的记录用 get_one 节点 ID/`search`。

**① 更新触发记录本身（start/table）：**

```python
{
    "type": "data_update",
    "name": "更新采购申请",
    "formTableCode": "cai_gou_shen_qing_swdd",
    "formTableName": "采购申请",
    "formTableSourceTaskId": "start",        # 更新触发记录
    "formTableSourceNodeType": "table",
    "updateFields": [
        {
            "field": "date_1775650764724_977189",   # 目标字段 model
            "val": {                                 # val 对象 = 变量引用
                "formNodeType": "system",
                "variableValue": "nowDate",
                "variableName": "当前日期",
            },
            "fieldType": "date",
            "options": {"format": "yyyy-MM-dd"},
            "valType": "variable",
        }
    ],
}
```

**② 更新 get_one 查询到的记录（search）：**

```python
# 前置：get_one 节点（自定义 ID 便于引用）
{
    "type": "get_one",
    "id": "task968425561527590912",          # ⚠️ 自定义 ID，后续 data_update 引用
    "name": "获取客户信息",
    "getType": 1,
    "formTableCode": "ke_hu_shen_qing_co38",
    "formTableName": "客户信息",
    "conditions": [...],                      # 查询条件
    "emptyAction": 0,
},
{
    "type": "data_update",
    "name": "更新客户信息",
    "formTableCode": "ke_hu_shen_qing_co38",
    "formTableName": "客户信息",
    "formTableSourceTaskId": "task968425561527590912",  # ⚠️ 指向 get_one 节点 ID
    "formTableSourceNodeType": "search",     # ⚠️ search=更新查询结果（写错 table 会更新错记录）
    "updateFields": [
        {
            "field": "select_1775649166520_177631",
            "val": "成交客户",                 # val 字符串 = 固定值
            "fieldType": "select",
            "type": "select",
        },
        {
            "field": "select_1775648798126_168238",
            "val": "个人客户",
            "fieldType": "select",
            "type": "select",
        },
    ],
}
```

**val 三种写法：**

| 写法 | 场景 | 示例 |
|---|---|---|
| 固定字符串 | 固定值 | `"val": "成交客户"` |
| 系统变量对象 | 当前日期等 | `{"formNodeType": "system", "variableValue": "nowDate", "variableName": "当前日期"}` |
| 字段引用对象 | 从其他节点取值 | `{"formNodeType": "table", "variableValue": "<字段model>", "formTableCode": "...", "variableName": "...", "formNodeId": "start", "formNodeName": "工作表事件触发"}` |

### 3. 删除记录（data_delete）

删除指定记录。同 data_update，用 `formTableSourceTaskId` + `formTableSourceNodeType` 指定删除目标。

```python
# 删除触发记录本身
{
    "type": "data_delete",
    "name": "删除记录",
    "formTableCode": "ke_hu_shen_qing_co38",
    "formTableName": "客户信息",
    "formTableSourceTaskId": "start",
    "formTableSourceNodeType": "table",
},

# 删除 get_one 查询到的记录（search）
{
    "type": "data_delete",
    "name": "删除一条记录",
    "formTableCode": "cai_gou_shen_qing_swdd",
    "formTableName": "采购申请",
    "formTableSourceTaskId": "task968429262686298112",   # get_one 节点 ID
    "formTableSourceNodeType": "search",
},

# 删除 get_more 查询到的多条记录（getMore，级联删除子表）
{
    "type": "data_delete",
    "name": "删除多条记录",
    "formTableCode": "sub_table_design_1775650992740_930671",
    "formTableName": "采购明细",
    "formTableSourceTaskId": "task968429275436982272",   # get_more 节点 ID
    "formTableSourceNodeType": "getMore",
    "formTableSourceGetDataType": 1,
},
```

### 4. 生产数据提炼的关键知识点

1. **`formTableSourceTaskId`/`formTableSourceNodeType` 三态**：`start`+`table`（触发记录）、get_one 节点 ID+`search`（查询结果）、get_more 节点 ID+`getMore`（多条结果）。**写错会导致更新/删除错对象**（实战踩坑：data_update 配成 table 会更新触发记录而非查询记录）。
2. **data_add 的 `formTableId` 默认格式**：`form_{节点ID}_{formTableCode}`，脚本自动生成，无需手写。
3. **data_get_more 取关联子表（selectType=3）**：`sourceTaskId`=start（或 get_one 节点 ID）+ `linkFormTableField`=关联字段 model（如 `link_record_1775650992740_930671`）。
4. **节点 ID 必须是时间戳格式**（`task{ts}001` 或 `Gateway{ts}`），禁止 UUID——mxGraph 渲染会失败。
5. **新增记录后回填关联**：上游 data_add 后接 data_add，用 `formNodeType: "plus"` + `variableValue: "_id"` 把新记录主键回填给关联字段。
6. **data_add 批量（addDataType=2）必须补全 4 个 source 字段**：`formTableSourceTaskId`/`formTableSourceNodeType`/`formTableSourceCode`/`formTableSourceId`（+`formTableSourceGetDataType`）。
