# 表单/字段（仅未点名，或点名不存在）

> 用户已点名应用+表单/字段时**禁止走本流程**，直接 create-dashboard / add-charts。  
> **例外见下方「字段缺失 / 近义确认」——点名了字段但表里没有，必须停问，禁止私自加字段。**

### 🚨 字段缺失 / 近义确认（严重：禁止私自改表）

**触发：** 用户已点名表单 + 维度/指标（如按【城市】聚合【销售额】），`fields` 查完发现 **点名 dim/val 不在表内**（或仅有近义字段，如只有「省份」没有「城市」）。

**强制动作（下一工具必须是询问，不是 `add_widget`）：**

1. 列出表内已有可绑字段（尤其近义：城市↔省份、地区↔省/市、金额↔销售额/售价）。
2. `ask_user` 二选一（或等价三选）：
   - **改用近义已有字段**（推荐，如用「省份」当维度）→ 获准后直接 `add-charts`，**零改表**
   - **授权加字段再灌数** → 仅此时才走 lowapp `add_widget` + mock（须用户明确同意）
   - **先不做 / 撤回** → 停
3. **禁止：** 未获明确授权就 `add_widget`、新建「城市」列、灌城市 mock、为凑口径改表结构。加图 skill **默认只消费已有字段**。

**与「禁止空等」的边界：** 「已点名仍 ask」禁的是技能域/对比方式/推荐控件等**口径已齐**的空问；**字段在表中物理不存在**属于描述与结构冲突，**必须问**。回顾案例 → `lessons.md` §33。

### 四步询问旧流程（已作废）

> 原四步（Step 0/A/B/C）教：询问表单来源 → 分普通/聚合两组展示 → 询问维/值 → **手写 dataType=4 config**。
> 现行为：未点名 → `form-field-inquiry.md` 简版询问（普通表单还是聚合表 → 维度/数值）→ 选型后一律 `add-charts` / `create-dashboard`（脚本自带表单字段回显 + CAND，字段名直接用用户原词）——**禁止手写 dataType=4 config**（`create.md` 硬禁令）。旧文细节不再收录。
