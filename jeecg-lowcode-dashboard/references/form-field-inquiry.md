# 表单/字段（仅未点名，或点名不存在）

> 已点名应用+表单/字段 → **禁止读本文件**，直接 `create-dashboard` / `add-charts`（`create.md`）。

## 点名 dim/val 不在表内（铁律）

`fields` 后发现点名维度/指标不在表内（或仅有近义，如只有「省份」没有「城市」）：

1. 列出表内可绑字段（尤其近义）。
2. 问：改用近义 / 授权加字段再灌数 / 先不做。
3. **禁止**未获明确授权就 `add_widget`。加图默认只消费已有字段。

## 未点名

「自行发挥」→ `create.md` 复合盘，不要走询问。  
否则问：普通表单还是聚合表 → 维度/数值。**不要手写 dataType=4 config**（走 `add-charts`）。  
未点名表单/字段四步询问旧全文 → `form-field-inquiry-full.md`（封存，手写 config 段已作废）；未点名过滤/按钮长交互模板 → `qqy-guide-archive.md`（旧全文）。
